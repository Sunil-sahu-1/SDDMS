12. HTTP METHODS SUMMARY
============================================================

GET
Used for retrieving data.

POST
Used for creating records and custom actions.

PUT
Used for complete updates.

PATCH
Used for partial updates.

DELETE
Used for deletion/archiving depending on the ViewSet.


============================================================
13. ROLE ACCESS
============================================================

ADMIN
- Full administrative access according to permissions.
- Access to legal records.
- Access to assigned application modules.

NORMAL_USER
- Access to permitted complaint/case/document resources.
- No Legal Officer-only operations.

POLICE_OFFICER
- Access to assigned cases.
- Access to assigned evidence.
- Access to permitted witness statements.

INVESTIGATOR
- Access to assigned investigation cases.
- Access to assigned evidence.
- Access to permitted witness statements.

LEGAL_OFFICER
- Access to legal reviews.
- Access to court hearings.
- Legal module operations according to permissions.


============================================================
14. IMPORTANT SECURITY RULE
============================================================

Never rely only on the endpoint URL for authorization.

Every protected API must validate:
- Authentication
- User role
- Case ownership/assignment
- Object-level permission
- Archived status where applicable

Sensitive operations should also generate audit logs.
